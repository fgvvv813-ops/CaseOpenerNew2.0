# CaseOpener New 2.0 — v0.0.017

## Моментальная продажа
- «Продать всё» отправляет один атомарный запрос серверу v0.0.017.
- Все скины продаются одной транзакцией: баланс и инвентарь обновляются одновременно по подтверждению API.
- В случае потери ответа приложение не повторяет списание автоматически и предлагает проверить инвентарь.
- Сервер проверяет ревизию и количество подтверждённых предметов до удаления.

## Уведомления
- При возвращении в игру синхронизируются пропущенные уведомления и регистрируется обновлённый Firebase-токен.
- Изменения на сервере: постоянная очередь FCM, повторные попытки и диагностика в веб-панели.
- Сообщения, отправленные с сайта, сохраняются в базе вне зависимости от работы push.
- Для фоновых push нужен Firebase-проект и сервисный ключ на API-хосте, а клиентские Firebase настройки — в GitHub Actions.
- Принудительная остановка Android или недоступность Google FCM могут задержать доставку.

## Стабильность сети
- Частые WebSocket ping, более быстрый reconnect с разбросом интервалов, повторные попытки подключения на сетевом уровне.
- Поддерживается региональный HTTPS/WSS адрес API через GitHub Actions variable GAME_API_BASE.
- Горизонтальное оформление, аккаунты, рулетка и все остальные игровые функции сохранены.
