# CaseOpener New 2.0 — v0.0.008

## Добавлено
- Общий онлайн-чат для всех игроков.
- Просмотр профиля другого игрока по нажатию на его имя в чате.
- В профилях отображаются лучший дроп, баланс монет, дата регистрации и количество открытий.

## Улучшено
- Сообщения появляются в чате без обновления страницы.
- Защита от спама: одно сообщение каждые 5 секунд для каждого игрока.
- Длина сообщений от 3 до 350 символов.
- История переписки сохраняется и загружается постепенно.
- Уведомления о новых сообщениях во вкладке чата.

Изменения относятся только к этой версии.
