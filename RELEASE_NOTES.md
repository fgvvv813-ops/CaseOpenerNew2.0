# CaseOpener New 2.0 — v0.0.009

## Улучшено
- Все кейсы и предметы загружаются из игрового сервера.
- Добавлена поддержка изображений предметов CS2, которые появляются в кейсах.
- Обновления кейсов и скинов отображаются во время игры без переустановки приложения.

Изменения относятся только к этой версии.
