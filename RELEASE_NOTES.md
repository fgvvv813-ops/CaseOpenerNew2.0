# CaseOpener New 2.0 — v0.0.002

## Добавлено
- Единая система версий с начальной версией 0.0.001 и текущей 0.0.002.
- Кнопка «Что добавлено в обновлении?» и отдельное окно с изменениями именно установленной версии.
- Отображение версии игры в шапке и профиле.

## Улучшено
- Адаптация для небольших экранов Android, планшетов и горизонтальной ориентации.
- Двухпанельный экран кейсов на широких устройствах.
- Адаптивная сетка инвентаря с вертикальной прокруткой.
- Защита от потери уже выпавшего предмета при повороте устройства: награда сохраняется до завершения анимации.
- Именованные APK и GitHub Releases по номеру версии.

Этот релиз продолжает версии 0.0.001. Здесь перечислены изменения **только v0.0.002**.
