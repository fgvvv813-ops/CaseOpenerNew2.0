# CaseOpener New 2.0 — v0.0.018

## Адаптивный горизонтальный интерфейс
- Верхняя панель подстраивается под узкие горизонтальные экраны: ник, уровень, баланс, уведомления и настройки остаются доступными.
- Высота нижней навигации и размер элементов адаптируются к маленьким экранам.
- Выбранная вкладка плавно подсвечивается, а настройка «уменьшить анимации» учитывается.
- Витрина кейсов выбирает ширину карточек по доступному пространству.
- Фильтры кейсов и инвентаря доступны через горизонтальную прокрутку без обрезания.
- Экран входа стал компактнее на небольших телефонах.
- Исправлено описание моментальной продажи: весь инвентарь продаётся одним запросом API версии 0.0.017+.

## Совместимость
- Требуется обновлённый игровой API 0.0.017 или новее для массовой продажи.
- Инвентарь, онлайн-события, обмены, чат, монеты и выбор открытия 1–5 кейсов работают по прежней серверной логике.
- Вертикальная ориентация остаётся отключённой.

## Серверные обновления
Отдельные Python-файлы API и сайта содержат схему БД 18 (SQLite WAL, memory-mapped чтение 32 МиБ, кэш 8 МиБ на подключение, лимит удерживаемого WAL 32 МиБ), ограниченные диагностические логи и пагинацию интерфейса админ-панели.
