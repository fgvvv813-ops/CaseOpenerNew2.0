# CaseOpener New 2.0

Native offline Android case-opening game written in Kotlin + Jetpack Compose.

## Download debug APK

Open **Actions** → **Build Android APK** → latest successful run → **Artifacts** → **CaseOpener-New-2.0-debug-apk**. Download the ZIP, extract `app-debug.apk`, then install on Android. GitHub login may be required.

[Open GitHub Actions](https://github.com/fgvvv813-ops/CaseOpenerNew2.0/actions/workflows/android.yml)

## Build locally

Use JDK 17, Android SDK 35, Gradle 8.9. Run `gradle :app:assembleDebug`.

## Features

Three cases, weighted drops, inventory, selling, offline currency and persistent progress. Rewards are fictional and use only virtual coins.
